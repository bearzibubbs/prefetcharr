# Prefetcharr K8s Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Fedora-based prefetcharr container image and all the Kubernetes + Tekton plumbing so every push to the fork builds, pushes, and auto-rolls out a dev deployment, with a separately-managed prod deployment.

**Architecture:** Multi-stage Fedora 43 Dockerfile building from the local fork checkout. Two Deployments in the `servarr` namespace (dev tracks `:latest`, prod pins a sha). ExternalSecret pulls API keys from Doppler and templates the full TOML config. Tekton pipeline builds+pushes to Quay and restarts the dev deployment. Separate beads agent pipeline fires on `.beads/` pushes.

**Tech Stack:** Fedora 43, Rust (cargo), Kustomize, OpenShift Pipelines (Tekton), External Secrets Operator with Doppler backend, beads issue tracker.

**Reference spec:** `docs/superpowers/specs/2026-04-22-prefetcharr-k8s-deployment-design.md`

**Branch context:** The fork's default branch is `latest`, not `main`. Commits land on `latest` throughout this plan.

```dockerfile
# Fedora-based multi-stage build of prefetcharr.
# Keeps the runtime image consistent with other arr-stack services
# (prowlarr, sonarr, radarr) which are all Fedora 43.

# ---------- Builder stage ----------
FROM registry.fedoraproject.org/fedora:43 AS builder

RUN dnf install -y \
      rust \
      cargo \
      gcc \
      openssl-devel \
      pkgconf-pkg-config \
    && dnf clean all

WORKDIR /src
COPY . .

RUN cargo build --release --locked

# ---------- Runtime stage ----------
FROM registry.fedoraproject.org/fedora:43

RUN dnf install -y \
      ca-certificates \
      openssl \
    && dnf clean all

COPY --from=builder /src/target/release/prefetcharr /usr/local/bin/prefetcharr

ENTRYPOINT ["/usr/local/bin/prefetcharr"]
CMD ["--config", "/etc/prefetcharr/config.toml"]
```

## Task 10: Add CI pipeline (pipeline-ci.yaml)

**Files:**
- Create: `ci/pipeline-ci.yaml`

Three tasks: clone, build-push, rollout-restart.

- [ ] **Step 1: Write `ci/pipeline-ci.yaml`**

```yaml
# ci/pipeline-ci.yaml
# CI pipeline: on any code push, build the Fedora image, push :latest and :<short-sha>
# to Quay, then restart the dev deployment to pick up the new image.
apiVersion: tekton.dev/v1
kind: Pipeline
metadata:
  name: prefetcharr-ci
spec:
  params:
    - name: repo-url
      type: string
    - name: revision
      type: string
      default: latest
    - name: quay-registry
      type: string
      default: quay.nekohouse.ca:8443
    - name: quay-credentials-secret
      type: string
      default: quay-push-secret
      description: "Secret with .dockerconfigjson for Quay push access"

  workspaces:
    - name: source

  tasks:
    - name: clone
      taskRef:
        resolver: cluster
        params:
          - {name: kind, value: task}
          - {name: name, value: git-clone}
          - {name: namespace, value: openshift-pipelines}
      workspaces:
        - name: output
          workspace: source
      params:
        - {name: url, value: $(params.repo-url)}
        - {name: revision, value: $(params.revision)}

    - name: build-push
      runAfter: [clone]
      workspaces:
        - name: source
          workspace: source
          mountPath: /workspace
      taskSpec:
        workspaces:
          - name: source
            mountPath: /workspace
        params:
          - name: revision
          - name: quay-registry
          - name: quay-credentials-secret
        volumes:
          - name: quay-auth
            secret:
              secretName: $(params.quay-credentials-secret)
              items:
                - key: .dockerconfigjson
                  path: config.json
        steps:
          - name: build-and-push
            image: quay.nekohouse.ca:8443/ci-framework/x86:latest
            workingDir: /workspace
            securityContext:
              privileged: true
            volumeMounts:
              - name: quay-auth
                mountPath: /root/.docker
                readOnly: true
            env:
              - name: REVISION
                value: $(params.revision)
              - name: REGISTRY
                value: $(params.quay-registry)
            script: |
              #!/usr/bin/env bash
              set -euo pipefail

              SHORT_SHA="${REVISION:0:8}"
              IMAGE="${REGISTRY}/init/prefetcharr"

              echo "=== Building ${IMAGE}:${SHORT_SHA} and :latest ==="
              podman build \
                --tls-verify=false \
                -f Dockerfile.prefetcharr \
                -t "${IMAGE}:latest" \
                -t "${IMAGE}:${SHORT_SHA}" \
                .

              echo "=== Pushing ${IMAGE}:${SHORT_SHA} ==="
              podman push --tls-verify=false "${IMAGE}:${SHORT_SHA}"

              echo "=== Pushing ${IMAGE}:latest ==="
              podman push --tls-verify=false "${IMAGE}:latest"
      params:
        - {name: revision, value: $(params.revision)}
        - {name: quay-registry, value: $(params.quay-registry)}
        - {name: quay-credentials-secret, value: $(params.quay-credentials-secret)}

    - name: rollout-restart
      runAfter: [build-push]
      taskSpec:
        steps:
          - name: restart
            image: registry.redhat.io/openshift4/ose-cli:latest
            script: |
              #!/usr/bin/env bash
              set -euo pipefail
              oc rollout restart deployment/prefetcharr-dev -n servarr
              oc rollout status deployment/prefetcharr-dev -n servarr --timeout=5m || true
```

```yaml
# ci/trigger.yaml
# EventListener with two Triggers on the same GitHub webhook:
#   - Code pushes (any file outside .beads/) → prefetcharr-ci pipeline
#   - .beads/ pushes                         → prefetcharr-agent pipeline
# Register the EventListener Route URL as a GitHub webhook (Content-Type: application/json).
apiVersion: triggers.tekton.dev/v1beta1
kind: EventListener
metadata:
  name: prefetcharr-listener
  namespace: servarr
spec:
  serviceAccountName: pipeline
  triggers:
    - name: ci-on-code-push
      interceptors:
        - ref:
            name: cel
          params:
            - name: filter
              value: >
                body.commits.exists(c,
                  (c.added + c.modified + c.removed).exists(f,
                    !f.startsWith('.beads/')))
      bindings:
        - ref: prefetcharr-github-push-binding
      template:
        ref: prefetcharr-ci-pipeline-template

    - name: agent-on-issue-push
      interceptors:
        - ref:
            name: cel
          params:
            - name: filter
              value: >
                body.commits.exists(c,
                  (c.added + c.modified + c.removed).exists(f,
                    f.startsWith('.beads/')))
      bindings:
        - ref: prefetcharr-github-push-binding
      template:
        ref: prefetcharr-agent-pipeline-template

---
apiVersion: triggers.tekton.dev/v1beta1
kind: TriggerBinding
metadata:
  name: prefetcharr-github-push-binding
  namespace: servarr
spec:
  params:
    - name: repo-url
      value: $(body.repository.clone_url)
    - name: revision
      value: $(body.after)

---
apiVersion: triggers.tekton.dev/v1beta1
kind: TriggerTemplate
metadata:
  name: prefetcharr-ci-pipeline-template
  namespace: servarr
spec:
  params:
    - name: repo-url
    - name: revision
  resourcetemplates:

      kind: PipelineRun

        generateName: prefetcharr-ci-
```
